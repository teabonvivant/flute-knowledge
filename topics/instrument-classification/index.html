Instrument classification

長笛分類

先按發聲方法、管體方向、音域及歷史用途分辨長笛家族，再理解現代 C 調長笛與其他橫笛的關係。分類不是只看名稱；同一「flute」字眼在不同語境可以指完全不同的樂器。

學完本頁：能按結構、音域及用途辨認主要長笛種類，並避免把西洋長笛與直笛、中國笛子或排簫混為一談。

015 分鐘

用四項特徵比較三種笛類

目標：把「長笛分類」的一項概念變成可觀察結果。

  1. 先記錄未改動的基準。
  2. 只處理「用四項特徵比較三種笛類」這一項。
  3. 重做基準並寫下一個可聽或可見分別。

達標：能具體說出改變了甚麼，而不是只用「好一點」作結論。

停止／退一步：如開始用力代償、音質持續惡化或注意力失焦，先休息再重設任務。

常見問題診斷

狀況先檢查下一步
對「長笛分類」只有模糊印象先說出你實際看見、聽見或做不到的現象，避免先猜原因。把問題縮成一個可測試變數，再選相應練習或來源。
練習時有改善，回到曲目又失效檢查練習速度、音域、節奏及注意焦點是否與曲目相差太遠。逐步增加原曲條件，每次保留一個成功判準。
不同來源給出相反建議核對來源身份、對象、樂器、年代及建議想解決的問題。並列觀點及適用情境；不要在證據不足時硬選唯一答案。

完整課堂

按步驟練習

  1. 01

    完全初學12 分鐘

    認識長笛各部件及正確名稱

    先認清頭管、管身、尾管、吹口孔、唇托、鍵杯、墊片、鍵軸及接合位置，之後的組裝、清潔和維修溝通才不會含糊。

  2. 02

    完全初學10 分鐘

    組裝及拆卸：避免扭曲鍵機械

    以管體光滑位置受力，配合輕微旋轉連接三節；不要握住鍵、鍵軸或唇托硬推。

  3. 03

    初級18 分鐘

    現代長笛家族及各自音域與用途

    比較短笛、C 調長笛、G 調中音長笛及 C 調低音長笛的記譜、實音、管體、角色及人體工學。

  4. 04

    初級20 分鐘

    開孔／閉孔、C／B 尾管、偏置／直列 G 的實際差異

    逐項比較用途、重量、手形、音域及維修，而不是把規格排列成必然升級路線。
