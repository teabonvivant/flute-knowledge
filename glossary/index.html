笛頭Headjoint
長笛帶有吹口及唇板的一節，演奏者的氣流在此與管內空氣振動互相作用。笛頭的切口、位置及與笛身的配合，都影響吹奏反應。讀相關主題 →
笛身Body joint
長笛主要音孔與按鍵所在的中段。組裝與拆卸時應握住合適的管身位置，避免用鍵系承受扭力。讀相關主題 →
尾管Footjoint
長笛末端的一節。常見 C 尾管可吹至低音 C，B 尾管則再增加低音 B；選擇時亦要考慮重量、反應與曲目需要。讀相關主題 →
唇板Lip plate
笛頭吹口周圍與下唇接觸的部分。穩定而舒服的接觸有助建立吹氣方向，實際位置需配合個人的身體條件。讀相關主題 →
口型Embouchure
演奏時嘴唇、周邊肌肉與吹口的協調方式。判斷應以發聲、音準、音色及身體自由為依據，不能只模仿外觀。讀相關主題 →
氣流Air stream
吹向長笛吹口的空氣流動。速度、方向和氣量會共同影響反應、音高及音色，練習時宜逐項比較。讀相關主題 →
發音Articulation
音符如何開始、延續、連接與結束的處理，包含吐音、連奏及不同音值的語氣。清楚發音不等於所有音都要短。讀相關主題 →
單吐Single tonguing
以舌頭的單一反覆動作分開音頭。練習時要聽舌頭加入後，氣流、拍子與音符長度是否仍然完整。讀相關主題 →
雙吐Double tonguing
交替使用前、後舌發音動作來處理快速音型。除了速度，也要比較兩種音頭的反應、力度與長短。讀相關主題 →
連奏Legato
讓相鄰音符形成連貫的音樂線條。長笛需要氣流與換指協調，避免音與音之間出現不必要的空隙或多餘音。讀相關主題 →
斷奏Staccato
以較分離的音符表達，常以音符上的圓點標示。實際長短與重量需配合速度、風格及句法，並非固定縮成同一比例。讀相關主題 →
圓滑線Slur
跨越一組音符的弧線，通常提示連貫演奏；對長笛而言常指線內不逐音重新吐音。仍要按版本與作品語境閱讀。讀相關主題 →
延音線Tie
連接兩個相同音高音符的弧線，把時值相加，後一個音不重新起音。它與連接不同音高的圓滑線用途不同。讀相關主題 →
顫音Vibrato
聲音中有規律的細微變動，用來參與音色和表情。速度、幅度及加入位置可隨句子與風格調整。讀相關主題 →
音準Intonation
音高與所採用的基準、旋律或和聲關係是否合適。調音器提供讀數，合奏時還需要聽自己的和聲角色。讀相關主題 →
拍頻Acoustic beats
頻率相近的聲音疊加時，可聽見規律的強弱起伏。比較適當的同音或音程時，這種起伏能協助辨認音高差異。讀相關主題 →
泛音Harmonics
與基頻相關的較高頻率成分。長笛也可透過氣流控制，在相同指法下吹出較高的振動模式，作音域與反應練習。讀相關主題 →
音域與音區Range / register
音域指可用音高的整體範圍；音區則指其中低、中、高等部分。各音區的反應、音色與控制條件需要分別熟悉。讀相關主題 →
力度Dynamics
音樂中聲音強弱的安排，包括 piano、forte 及漸強漸弱等。力度關係需配合作品、音域、合奏與場地理解。讀相關主題 →
樂句處理Phrasing
依旋律、和聲、節奏及結構，把音符組成有方向的語句。換氣、重音、音色與時間變化都參與其中。讀相關主題 →
氣口Breath mark
為換氣選定的位置或譜上記號。安排時兼顧句法、拍子與合作聲部，讓呼吸之後的聲音仍按音樂需要接續。讀相關主題 →
拍子Pulse / beat
音樂中可感受到的基本時間脈動。節奏在拍子之上形成長短與重音，休止期間也需要保有內在拍感。讀相關主題 →
細分拍子Subdivision
把一拍分成較小而規律的單位，協助理解附點、切分及複雜節奏。細分應支援流動，最後仍要聽見較大的拍子。讀相關主題 →
切分音Syncopation
重音或延續跨過預期強拍，形成與基本拍感交錯的節奏。演奏時仍要清楚知道拍子位置，才有穩定的張力。讀相關主題 →
視奏Sight-reading
初次閱讀樂譜時，把拍子、音高與基本表達連續呈現。開始前先看調號、拍子、反覆與主要難點，演奏中保持往前讀。讀相關主題 →
替代指法Alternative fingering
標準指法以外、為特定連接、音準或音色採用的按鍵組合。需要在實際音域、力度及前後音裏驗證效果。讀相關主題 →
開孔鍵Open-hole keys
部分按鍵中央留有孔，需要指腹或合適孔塞密合。選擇應配合手形與曲目需求，並非演奏程度的標籤。讀相關主題 →
伯姆系統Boehm system
由 Theobald Boehm 的長笛設計發展而來的孔位與鍵系安排，是現代音樂會長笛的重要基礎。讀相關主題 →
巴羅克橫笛Traverso / Baroque flute
用於巴羅克音樂實踐的歷史橫笛，常見木製及單鍵形式。其構造、指法與音高條件與現代長笛不同。讀相關主題 →
短笛Piccolo
長笛家族的高音樂器，常見形式比記譜高一個八度。它在樂團中可加倍旋律、改變音色，也可擔任獨立聲部。讀相關主題 →
中音長笛Alto flute
常見為 G 調，實際聲音比記譜低純四度。較大的管身與不同握持條件，帶來有別於普通長笛的音色和反應。讀相關主題 →
低音長笛Bass flute
常見為 C 調，實際聲音比記譜低一個八度，通常使用彎曲笛頭。在長笛合奏與室內樂中提供較低音域。讀相關主題 →
管弦樂片段Orchestral excerpt
從完整管弦樂作品抽出的重要聲部段落。準備時除了技巧，還要閱讀總譜、了解入口和合作聲部。讀相關主題 →
華彩段Cadenza
協奏曲等作品中突出獨奏者的段落，可能由作曲家寫定或另有版本。自由程度及回到合奏的方法需依作品安排。讀相關主題 →
室內樂Chamber music
由較小編制樂器合作的音樂。聲部之間的對話、平衡、提示與共同呼吸，是排練的重要工作。讀相關主題 →
多音Multiphonics
透過特定指法及氣流等條件，同時產生可辨認的多個音高或複合音響。結果受樂器、力度與音域影響。讀相關主題 →
花舌Flutter-tonguing
利用舌部或其他適當的顫動方式產生連續顫舌音效。不同演奏者的適用方法有差異，應循序學習並保持舒適。讀相關主題 →
原典版Urtext edition
以原始資料與校勘研究為基礎的樂譜版本。閱讀時仍應看前言、資料來源和編輯記號，了解具體的整理選擇。讀相關主題 →
總譜Full score
把多個聲部按時間對齊排列的樂譜。它能顯示和聲、配器與合作關係，幫助演奏者把自己的聲部放回作品整體。讀相關主題 →
師承Teaching lineage
音樂家之間的學習與教學關係。整理時應分清長期主修、短期課程及間接影響，並保留具體來源。讀相關主題 →
