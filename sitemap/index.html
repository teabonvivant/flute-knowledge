初遇長笛 →

  • 第一個清楚的音，像窗縫裏的一線光
  • 打開笛盒之前：一堂課由準備開始
  • 成年後才學長笛，把起點還給自己
  • 小朋友適合開始了嗎？先看伸手與呼吸
  • 多年後再開笛盒，先和舊日的自己握手
  • 託得穩，不必握得緊
  • 笛頭與整支長笛，是兩種不同的課堂
  • 五個音也能説一段話
  • 第一首曲子，應該有一點餘裕
  • 把「吹不好」改成一個可以回答的問題

聲音的細節 →

  • 長音不是一條直線，而是一段細聽
  • 氣快一點，未必就要吹得更大聲
  • 吸氣之前，先知道這一句要走到哪裏
  • 低音的門，輕輕推也要打得開
  • 高音不必像喊叫：為聲音留一點空間
  • 弱奏不是退場，是換一種説話距離
  • 調音器亮起之前，先問耳朵聽見甚麼
  • 不只明亮與温暖：寫一頁自己的音色詞典
  • 顫音是一種選擇，不是一層固定的糖衣
  • 八度之間，搭一座不驚動旋律的橋

拍子與手指 →

  • 節拍器不是監考員，是一個守時的同伴
  • 音階卡住的地方，往往只住着兩個音
  • 舌頭輕輕碰門，氣流仍然往前走
  • 雙吐的後半步，也值得被聽見
  • 六個小音符，可以走成兩種步伐
  • 休止符裏，音樂仍然走着
  • 附點的長短，別交給印象代算
  • 切分音偏離重拍，腳下仍要有地面
  • 快句先走短路，再接成長線
  • 最後一個音，也有應到的時間

譜上的風景 →

  • 五條線上的路標：讀譜不必逐粒猜
  • 第一個音之前，先讀調號
  • 一個升降號，會留在小節裏多久？
  • 兩條相似的弧線，説的是不同事情
  • 在譜上寫一個逗號，先讀懂整句話
  • 強弱記號，也可以讀成遠近
  • 把耳朵放低一點，旋律會多一層意思
  • 視奏前的半分鐘，眼睛先走一遍
  • 裝飾音不是花邊，它要在句子裏有位置
  • 同一首曲子，為何兩本譜不完全相同？

練習日常 →

  • 只有十五分鐘，也可以練得有頭有尾
  • 練習簿不必寫滿，只要下次看得懂
  • 錄下自己之後，先學會怎樣聽
  • 放下長笛的幾分鐘，也屬於練習
  • 在小小的香港房間裏，安放一段笛聲
  • 沒有吹奏的一天，仍可以讀懂一頁音樂
  • 今天吹不順，先不要替整個人下結論
  • 一星期後回頭聽，進步可能藏在小地方
  • 背譜不只靠手指，還要有幾條回家的路
  • 再吹一次之前，先留一個問題

與人合奏 →

  • 第一場合奏，從一起吸氣開始
  • 鋼琴響起時，長笛先學會聽
  • 對音之後，音準才真正開始
  • 休止的小節裏，也有你的工作
  • 今天不唱主旋律，也可以吹得很好
  • 譜上的鉛筆，是下一次排練的記憶
  • 一起開始之外，還要一起放手
  • 小房間裏的室內樂，藏不住細節
  • 管絃樂片段，不能只剩長笛那幾行
  • 排練時怎樣説話，音樂就怎樣靠近

聆聽札記 →

  • 聽一張唱片，可以先只聽一句
  • 同一首曲子的兩扇窗
  • 耳筒裏的長笛，也帶着一個房間
  • 唱片封套上的小字，值得慢慢讀
  • 短笛一亮起，樂團的天空就變了
  • 木笛的一口氣，帶我們走近另一種時間
  • 第一次聽當代長笛，先放下「像不像旋律」
  • 聆聽筆記，不必寫成樂評
  • 有些表情，藏在沒有吹出的地方
  • 十張唱片不如一張，先建立自己的小書架

長笛與時代 →

  • 銀色的長笛，為甚麼仍叫木管樂器
  • 伯姆改變的，不只是長笛的外表
  • 舊教本翻開時，先問它想教甚麼
  • 把女性長笛家的名字，放回音樂的正文
  • 師承是一張地圖，未必是一種聲音
  • 你手上的樂譜，也有人替它作過選擇
  • 談「學派」之前，先聽見不同的人
  • 遇見另一種笛，先學會叫它的名字
  • 玻璃櫃裏的長笛，是一份立體的史料
  • 查一位音樂家，名字相同還不夠

笛盒內外 →

  • 第一支長笛，先選每天願意拿起的那一支
  • 開孔與閉孔，是配置選擇，不是程度標籤
  • 多出來的低音鍵，會改變甚麼
  • 收笛的幾分鐘，也是練習的一部分
  • 一個音忽然吹不出，先別怪自己
  • 潮濕日子裏，替笛盒留一個安穩角落
  • 換笛頭之前，先讓比較公平一點
  • 長笛家族的低聲部，像房間多了一層影子
  • 帶長笛出門，讓旅程少一點碰撞
  • 保養不是等到吹不出聲才開始

走向舞台 →

  • 第一場演出，可以從一個小房間開始
  • 一份小節目，也可以有起承轉合
  • 一鏡到底的練習，教我們繼續往前
  • 上台前，把注意力放回可以做的事
  • 到了演奏廳，先聽房間回你甚麼
  • 考級準備，也要留一條音樂的線
  • 翻譜、燈光與譜架，都是演出的一部分
  • 錄一段自己，讓耳朵走到譜架外面
  • 掌聲之後，怎樣把演出帶回練習室
  • 吹完一百次之後，仍然可以像初次那樣聽
